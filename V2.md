# HERD LP Node — v2 plan (downloadable private node)

**Repo:** [i-am-aemon/ANSEM_LP_HERD_Node](https://github.com/i-am-aemon/ANSEM_LP_HERD_Node) (Public)  
**Audience:** people who clone this repo and run their **own** private node with their own keys.

## v1 today

- Runnable multi-pool cell: setup UI, fee mix, doctor, dry/live modes.
- Operator keeps keys in local `.env` (never committed).
- Hub points operators at this public fork for “run your own node.”

## v2 goals

1. **Clone → configure → run** is the happy path for a non-ansem operator (docs + examples, not a hosted SaaS).
2. Clear separation: public OSS node vs private creator-fees / imperial cells (01–07).
3. Creator-designed improvements from private `dev creator` cells promote here only after they are safe for strangers’ wallets.
4. Better first-run: `.env.example`, doctor checks, and README so download-and-run needs fewer tribal notes.
